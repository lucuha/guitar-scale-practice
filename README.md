# ジャズ指板トレーナー

ブラウザだけで動くギター指板の練習ツールです。`index.html` をブラウザで開くだけで使えます(ビルド不要・外部ライブラリなし)。

## 3つのモード

| モード | 内容 |
| --- | --- |
| 指板ビューア | 12キー × スケール/アルペジオ(モード、メロディック・マイナー、オルタード、ディミニッシュ、各種7thアルペジオ等)を度数 or 音名で表示。5フレット幅のポジションに絞って上行再生。 |
| 音名クイズ | 「この音は？」「弦で探す」「全部探す」「度数は？」の4種類。弦・フレット範囲を絞れる。音名ごとの正解率をヒートマップ表示(ブラウザに保存)。 |
| コード進行 | ii–V–I、マイナー ii–V–i、循環、ジャズ・ブルース等をメトロノーム付きで再生し、今のコードのコードトーンを表示。次のコードの音・共通音も予告。 |

## 練習の目安(1日20分)

1. 音名クイズ 5分 — 弦を絞って反射で答えられるまで
2. 指板ビューア 5分 — 1ポジションで maj7 / m7 / 7 / m7♭5 アルペジオを度数を言いながら
3. コード進行 10分 — ガイドトーン(3度・7度) → アルペジオ → スケールの順。キーは4度ずつ移動
