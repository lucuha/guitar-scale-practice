ルート 3度 5度 7度 テンション・その他

まずは 5フレット幅の1ポジション に絞り、ルート・3度・5度・7度の場所を度数で言えるようにします。次に「音名」に切り替え、同じ形を別のキーへ動かすと、形と音名が結びつきます。押さえた場所をタップすると音が鳴ります。

モード
コード
表示
　
ルート 3度 5度 7度 テンション・その他 コードフォームの音

開放コードの C・A・G・E・D の形 を平行移動すると、1つのコードが指板上で5つの形としてつながります(順番は常に C→A→G→E→D→C…)。まず1つのキーで5つの形を低い方から順に押さえ、各形のルートがどの弦にあるかを言えるようにします。次に「重ねて表示」でアルペジオやスケールを出し、その形の枠の中で弾けるようにします。

モード
出題する弦
　

1日5分、最初は弦を1〜2本に絞り、正解率が90%を超えたら弦を増やします。全部探す は1つの音を全弦で見つける練習で、指板全体の地図づくりに効きます。度数は？ はルートからの距離を形で覚える練習で、アドリブで「今のコードの3度はどこ？」に即答する力になります(答えると2音が鳴るので耳も鍛えられます)。答える前に音名を声に出すと定着が速くなります。

練習
表示
Dm7ii7
　
ルート 3度 5度 7度 / 6度 次のコードの音 共通音 ガイドトーン・ライン (矢印で次へ)

各コードの 3度と7度(ガイドトーン) は、次のコードへ共通音か半音でつながります。ガイドトーン・ライン をONにすると、その動きを矢印と下の音列で表示します。「表示する音」をシェルやドロップ2にすると、前のコードから一番近い押さえ方を自動で選びます(ボイスリーディング)。①ガイドトーンだけ → ②アルペジオ → ③スケール、の順で進めます。スペースキーでスタート/ストップ。

コードが鳴っている間に、指定された音を ポジションの枠の中で タップします。最初はテンポ60前後、ポジションを1つに固定して始めます。間違えやすい度数・反応が遅い度数は自動で多めに出ます。止めた状態でも、答えると次のコードへ進みます。

1日20分の練習メニュー例
  1. 音名クイズ 5分：今週は5弦と6弦だけ、など範囲を絞って反射で答えられるまで。
  2. 指板ビューア 5分：1ポジションで maj7 / m7 / 7 / m7♭5 のアルペジオを度数を言いながら弾く。
  3. CAGED 5分(週に数回、指板ビューアと交代で)：1キーで5つの形を順に押さえ、「形は？」クイズで形の名前とルートの弦を即答できるように。
  4. コード進行 10分：ii–V–I をゆっくりのテンポで。ガイドトーン・ラインを見て弾く → 「タップで答える」で確認 → アルペジオ → スケールの順。慣れたらキーを4度ずつ(C→F→B♭…)動かす。
